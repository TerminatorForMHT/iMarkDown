# iMarkDown UI 规范

> 视觉方向：macOS 26 Liquid Glass · 低饱和环境色 · 内容优先的分栏写作界面。
> 配套高保真稿：[ui-preview.html](../design/ui-preview.html)（浏览器直接打开）。

---

## 1. 设计原则

1. **内容优先**：玻璃只存在于窗口 chrome 与浮动层，正文始终落在高不透明度的“纸面”上，保证长时间阅读舒适。
2. **一层玻璃一条路径**：能用系统材质就不自绘；SwiftUI 浮层用 `.glassEffect`；AppKit 层级用 `NSGlassEffectView`。
3. **安静的高亮**：只有脏状态、保存失败使用警示色；其余强调色统一为系统蓝。
4. **克制的信息密度**：状态信息集中在一个浮动胶囊里，不在界面四周重复。
5. **原生手感**：所有按钮、菜单、快捷键、焦点与拖拽行为遵循 macOS 习惯。

## 3. 材质层级

| 层级 | 载体 | 材质 | 用途 |
| --- | --- | --- | --- |
| L0 | 窗口背景 | MeshGradient（低饱和） | 提供折射内容，不承载文字 |
| L1 | 侧边栏 / 工具栏 | 系统 Liquid Glass | 导航与全局操作 |
| L2 | 内容卡片 | 不透明纸面（浅 `#FFFFFF` / 深 `#161618`），1px 高光描边 | 源码与预览 |
| L3 | 浮动 HUD | `NSGlassEffectView`（regular，轻 tint） | 字数、行数、保存状态 |
| L4 | 菜单 / 弹窗 | 系统 | 导出、设置、确认框 |

卡片阴影：浅色 `black 14% / radius 24 / y 12`；深色 `black 45% / radius 24 / y 12`。
玻璃描边：白色 18%（HUD）、卡片描边白色 55%（浅）/ 10%（深）。

## 6. 组件规范

### 6.1 视图分段控件

- 位置：工具栏右侧，固定宽 168pt。
- 选项：源码 / 分栏 / 预览（⌘1 / ⌘2 / ⌘3）。
- 样式：系统 segmented，选中态跟随系统强调色与玻璃容器。

### 6.2 浮动状态 HUD

- 结构：`状态点 · 保存文案 | 字数 · 行数 · 阅读时间`。
- 状态色：灰（未命名）/ 橙（未保存）/ 蓝（保存中）/ 绿（已保存）/ 红（失败）。
- 交互：不拦截点击；悬停不放大，避免干扰写作。
- 无障碍：合并为一句标签，数字变化使用 `numericText` 过渡。

### 6.3 侧栏

- 顶部品牌区：28pt 圆角渐变图标 + 名称 + “Liquid Glass”副标。
- 文件树：打开文件夹后按目录层级展示 Markdown / 文本文件；目录按需展开，当前文档高亮蓝点；区段标题提供打开文件夹、刷新、关闭文件夹三个图标按钮；未打开文件夹时显示“打开文件夹”入口。
- 最近列表：文档图标 / 名称 / 省略中间路径 / 当前文档蓝点；失效文件 45% 透明度并禁用。
- 底部操作：玻璃按钮组（新建为 prominent），与系统材质合并。

### 6.4 空状态

- 编辑器内：源码占位“开始书写 Markdown…”；预览占位“预览将在这里实时呈现”。
- 侧栏：无最近文件时给出两行说明，不放大插图。

### 6.5 设置窗口

- 分组：外观 / 排版 / 行为 / 关于。
- 滑块实时生效，字号显示整数值并等宽对齐。
- 提供“恢复默认字号”。

## 7. 动效

| 场景 | 动效 |
| --- | --- |
| HUD 显示/隐藏 | `snappy 0.22s` + 自底部 8pt 上移 + 淡入 |
| 数字变化 | `numericText` 过渡 |
| 主题切换 | 系统外观切换，Web 侧立即更新 CSS 变量，不做渐变过渡（避免阅读闪烁） |
| 分栏切换 | 立即重排，CodeMirror 下一帧 `refresh` |
| 玻璃按钮 | 使用系统 `.glass` 自带按压与高光，不自定义缩放 |

---

## 8. 无障碍与降级

- 低于 macOS 26：玻璃回退到 `NSVisualEffectView(.hudWindow)`，按钮回退标准样式。
- “降低透明度 / 提高对比度”：依赖系统材质自动响应；卡片本身已是不透明表面。
- HUD 使用 `.accessibilityElement(children: .combine)`，朗读“已保存 12:04，1284 字，96 行”。
- 所有图标按钮带 `.help` 文案；主操作均有菜单项与快捷键，不依赖鼠标。
- 颜色不是唯一信息载体：保存状态同时有文字描述。
