顶部工具栏重构：透明悬浮 + 覆盖时才模糊

参考 macOS 系统设置顶部行为：顶部区域本身没有背景，只有正文真正滚到控件后方、形成重叠时，才出现一条与主编辑区贴合的轻淡材质，并在下缘柔和过渡。当前实现的圆角卡片、导航栏标题与整条工具栏背景都会移除。

下方为浅色 / 深色 / 降低透明度三种状态的设计稿，可直接点击按钮切换滚动状态查看效果。

一、浅色模式：状态 A（正文未进入顶部）

只有悬浮控件；顶部容器完全透明，正文标题位于阅读流中，正文顶部保留可滚动的留白。

一、核心目标

顶部区域应当像系统设置一样克制：文档标题属于正文，控件只作为悬浮操作存在。正文未滚动到控件后方时，顶部完全透明，不应出现任何面板、底色或分隔线。

二、滚动状态

只有当正文的实际内容边界进入顶部覆盖区域，才显示一条与编辑区贴合的轻淡材质，下缘柔和过渡。材质位于控件下层，标题与按钮始终保持清晰。

// 判定的是重叠，而不是 scrollTop > 0
overlap = contentRect.top < overlayBottom
compactTitle = documentTitleRect.bottom < overlayBottom

一、核心目标

顶部区域应当像系统设置一样克制：文档标题属于正文，控件只作为悬浮操作存在。

二、滚动状态

只有当正文的实际内容边界进入顶部覆盖区域，才显示材质；下缘柔和过渡。

三、状态矩阵

降低透明度开启时，使用系统可读性替代背景，不强行保留模糊效果。

项目设计说明.md
源码分栏预览

降低透明度：以不透明系统底色替代模糊，仍保持贴边、无卡片、无分隔线的结构。

三、关键尺寸与布局关系

项目建议值说明
顶部覆盖区高度56–72 pt（图示 64）与正文滚动内容共享背景，纵向不占布局，正文可滚到其后方。
左右内容边距20–24 pt控件距编辑区左/右边缘；紧凑标题与分段控件同一行居中。
控件高度28–32 pt（图示 30）分段控件与图标按钮等高；图标按钮为 30×30 圆角方形。
模糊下缘过渡12–20 pt（图示 16）用渐变遮罩柔化材质下沿，不出现硬边、粗阴影或分隔线。
正文顶部留白约 100–120 pt属于滚动内容，首行不被控件遮挡；不是固定挤占可视区域的 padding。

四、触发判定与实现要点

问题方案
如何判断「正文进入顶部」不用 scrollTop > 0。JS 侧以滚动容器的可视窗口为 root，顶部覆盖条带为判定区域（IntersectionObserver + 顶部 rootMargin），观察正文首个内容块与文档大标题；上报「是否重叠」「大标题是否移出」两个布尔值，Swift 侧只负责呈现。
三种模式怎么处理预览读 #preview-scroll、源码读 CodeMirror 的 scroller；分栏只取当前可见窗格，未显示的窗格滚动不触发。切换模式或打开新文件后重新观察并立即同步一次状态。
原生材质顶部用 NSVisualEffectView（.withinWindow + 系统 header 材质）或 SwiftUI .ultraThinMaterial，只铺在编辑区顶部条带；控件置于材质之上，因此按钮与标题始终清晰。
下缘柔和过渡材质视图加纵向渐变遮罩（mask-image / CAGradientLayer），最后 16pt 渐隐，避免硬切。
交互不被打断顶部容器仅控件区域命中测试；透明留白 allowsHitTesting(false)，正文的滚动、选择、链接点击不受影响。
无障碍开启「降低透明度」时切换为不透明系统底色；「减少动态效果」时去掉出现/消失过渡，仅做瞬时切换。
防闪烁状态变化合并到一次布局周期，连续滚动 / 惯性 / 回弹时以最终重叠结果为准，避免在临界点反复切换。

五、底部状态提示（保留，不做改动）

即现有 StatusHUDView：编辑区底部居中的悬浮玻璃胶囊，与顶部改造互不影响。

项目说明
显示内容状态圆点 + 保存状态与上次保存时间（如「已保存 14:32」）+ 字数 + 行数。去掉「预计阅读时长」。
位置与尺寸编辑区底部居中，距底约 22–30 pt，高 30 pt，胶囊圆角 15 pt。
与顶部改造的关系完全独立：不参与顶部模糊，不随滚动隐藏，也不因模式切换重新排布。
状态反馈自动保存中为蓝色、未保存为橙色、失败为红色、已保存为绿色；「自动保存已暂停」沿用现有文案。
开关继续由设置中的「显示状态提示」控制；关闭时不占位、不影响正文布局。

六、需要从当前实现中移除的部分

现状调整
编辑区圆角卡片背景 + 阴影 + 描边移除。编辑区与顶部共享连续背景，窗口内不再有独立卡片边界。
navigationTitle / navigationSubtitle 常驻标题标题回到正文；仅在滚动重叠且大标题移出后显示紧凑标题。
系统工具栏作为独立标题栏改为覆盖在滚动内容上的固定控件层，背景随重叠状态显隐。
侧栏与底部操作保持不变，不被顶部材质覆盖或重新模糊。
